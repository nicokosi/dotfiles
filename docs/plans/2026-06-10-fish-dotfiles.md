# Fish Dotfiles Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Populate the `.dotfiles` repo with the current fish shell configuration, managed via GNU Stow.

**Architecture:** A `fish/` stow package mirrors the `~/.config/fish/` structure. Only hand-authored files are tracked (generated tide files are excluded via `.gitignore`). A `install.sh` bootstrap script + `README.md` make setup reproducible on a new machine.

**Tech Stack:** fish shell, GNU Stow, fisher (plugin manager), tide v6 (prompt)

### Task 2: Create install.sh bootstrap script

**Files:**
- Create: `install.sh`

- [ ] **Step 1: Create install.sh**

Create `~/.dotfiles/install.sh` with this content:

```bash
#!/usr/bin/env bash
set -euo pipefail

DOTFILES="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

# 1. Check stow is available
if ! command -v stow &>/dev/null; then
  echo "ERROR: GNU Stow is not installed."
  echo "Install it with: sudo apt install stow  OR  brew install stow"
  exit 1
fi

# 2. Stow fish package
echo "→ Stowing fish config..."
cd "$DOTFILES"
stow --verbose fish

# 3. Install fisher if not present
if ! fish -c "type -q fisher" &>/dev/null; then
  echo "→ Installing fisher..."
  fish -c "curl -sL https://raw.githubusercontent.com/jorgebucaran/fisher/main/functions/fisher.fish | source && fisher install jorgebucaran/fisher"
fi

# 4. Install plugins
echo "→ Installing fish plugins..."
fish -c "fisher update"

echo ""
echo "✓ Done! Run 'tide configure' to set up your prompt."
```

- [ ] **Step 2: Make it executable**

# dotfiles

Personal dotfiles managed with [GNU Stow](https://www.gnu.org/software/stow/).

## Setup (new machine)

### Prerequisites

- fish shell installed
- GNU Stow installed (`sudo apt install stow` or `brew install stow`)

### Install

```sh
git clone <your-repo-url> ~/.dotfiles
cd ~/.dotfiles
./install.sh
```

Then run `tide configure` to set up the prompt appearance.

### What's included

| Package | Path | Description |
|---------|------|-------------|
| `fish` | `~/.config/fish/` | Fish shell config + fisher plugins |

### Adding a new tool

1. Create a directory `<tool>/` mirroring the target path structure
2. Add your config files inside it
3. Run `stow <tool>` from `~/.dotfiles/`
4. Commit

### Notes

- `fish_variables` (universal variables, incl. tide theme) is **not tracked** — regenerate with `tide configure`
- Tide functions/completions are **not tracked** — regenerated by `fisher update`
```
