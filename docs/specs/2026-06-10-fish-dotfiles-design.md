# Fish Dotfiles Setup Design

**Date:** 2026-06-10  
**Status:** Approved

## Goal

Initialise the `.dotfiles` git repository with the current fish shell configuration, using GNU Stow for deployment.

## Repository Structure

```
.dotfiles/
  fish/
    .config/fish/
      config.fish       # Main fish config (interactive session bootstrap)
      fish_plugins      # Fisher plugin list (tide v6)
      conf.d/           # Drop-in config files (currently empty)
  install.sh            # Bootstrap script
  README.md             # Setup instructions
```

## What Is Tracked

| File | Reason |
|------|--------|
| `fish/config.fish` | Main shell config |
| `fish/fish_plugins` | Declares fisher plugins (source of truth for plugins) |
| `fish/conf.d/` | Directory for future drop-in configs |
| `install.sh` | Reproducible setup on new machines |
| `README.md` | Human-readable setup guide |

## What Is Excluded

| File | Reason |
|------|--------|
| `functions/` (tide) | Auto-generated by `fisher update` |
| `completions/tide.fish` | Auto-generated by fisher |
| `fish_variables` | Universal variables — may contain sensitive data; tide config recreated via `tide configure` |
| `conf.d/_tide_init.fish` | Auto-generated by tide |

A `.gitignore` inside `fish/.config/fish/` enforces these exclusions.

## Deployment

On a new machine:

```sh
git clone <repo> ~/.dotfiles
cd ~/.dotfiles
./install.sh
```

The `install.sh` script:
1. Checks that `stow` is available (errors with install hint if not)
2. Runs `stow fish` to create symlinks under `~`
3. Installs fisher (via `curl`) if not already present
4. Runs `fisher update` to reinstall plugins from `fish_plugins`

After setup, run `tide configure` to restore prompt appearance.

## Stow Strategy

- Package per tool (e.g., `fish/`) — extensible for future tools (git, nvim, etc.)
- `stow fish` run from `~/.dotfiles/` creates `~/.config/fish/` symlinks
- Existing files at target paths must be removed/backed up before stowing
